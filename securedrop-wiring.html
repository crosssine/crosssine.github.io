Brown-out
ESP32-CAM กิน current peak สูงมากช่วง WiFi TX + ถ่ายภาพ (ถึง ~1A) — ใช้ Buck Converter แยกจาก ESP32 หลัก หรืออย่างน้อยต้องมี capacitor 470–1000 µF คร่อมขา 5V/GND ของแต่ละบอร์ด ไม่เช่นนั้นบอร์ดจะรีสตาร์ทเอง
Power Domain
ห้ามจ่ายไฟ Solenoid / UV / Siren ผ่านขา 5V ของ ESP32 โดยตรง ต้องผ่าน Relay ที่แยก power domain เท่านั้น
Protection
ใส่ ฟิวส์ 3A ที่ทางเข้า 12V และ ไดโอด Flyback คร่อม Solenoid Lock เพื่อกันแรงดันย้อนกลับ (back-EMF) ทำลาย Relay/MCU

06

ความปลอดภัยด้านไฟฟ้า

Ground
แยก ground plane ระหว่างวงจร 12V (Solenoid/UV/Siren) กับวงจรลอจิก 3.3V/5V แล้วเชื่อมกันที่ จุดเดียว (single point ground) เพื่อลด noise
Isolation
ใช้ relay module ที่มี opto-isolator ในตัว เพื่อกันไฟกระชากย้อนเข้า ESP32
UV-C
UV-C 275nm อันตรายต่อดวงตา/ผิวหนัง ต้องมี hardware interlock แบบ fail-safe ไม่พึ่ง software อย่างเดียว — ต่อ magnetic door sensor แบบอนุกรม (in-series) กับสายไฟเลี้ยงของ UV relay จริงๆ เพื่อว่าแม้ software ค้าง UV ก็ติดไม่ได้เมื่อประตูเปิด
Enclosure
UV-C module ต้องอยู่ในช่องแยกที่ไม่มีแสงรั่วออกสู่ภายนอกหรือช่องที่คนสัมผัสได้
Fuse
ใส่ fuse/PTC ที่ทุกสาย 12V เพื่อป้องกันไฟฟ้าลัดวงจร
07

เช็คลิสต์ก่อนจ่ายไฟครั้งแรก

  • 1
    วัด relay logic ก่อน — เช็คว่าโมดูลเป็น active-HIGH หรือ active-LOW ด้วยมัลติมิเตอร์ก่อนต่อเข้า GPIO จริง
  • 2
    ต่อ flyback diode คร่อม solenoid ก่อนจ่ายไฟ 12V เข้า relay #1 เสมอ
  • 3
    เช็ค common ground ทุกบอร์ด (ESP32 หลัก + CAM 2 ตัว + relay module) ต้องเชื่อมถึงกัน
  • 4
    แยก buck converter สำหรับ ESP32-CAM หรือใส่ capacitor 470–1000µF คร่อม 5V/GND ก่อน flash โปรแกรม
  • 5
    ทดสอบ voltage divider ของ HC-SR04 Echo ด้วยมัลติมิเตอร์ว่าลดจาก 5V เหลือ ~3.3V จริง ก่อนต่อเข้า GPIO18
  • 6
    ยืนยัน hardware interlock ของ UV-C — ลองเปิดประตูตอน UV relay ทำงานอยู่ ไฟต้องดับทันทีแม้ software ค้าง
  • 7
    ใส่ fuse 3A ที่ทางเข้า 12V ก่อนเสียบปลั๊ก adapter ครั้งแรก
