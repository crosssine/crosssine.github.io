SecureDrop Wiring Guide

06

ลำดับทำงานหลังต่อสายครบ

1. เปิดไฟ → Main ล็อกค้างไว้ → เชื่อม WiFi → พร้อมสแกน
2. สแกนบาร์โค้ดที่ลงทะเบียน (เช่น TH1234567890)
3. ปลดล็อก 5 วินาที → เรียก http://192.168.1.101/capture
4. ส่ง Telegram (เลขพัสดุ + เวลา + รูป) → ล็อกกลับ
5. ถ้าบาร์โค้ดผิด / ใช้แล้ว → ไม่ปลดล็อก + ส่งแจ้งเตือน Telegram
07

เช็คลิสต์ก่อนจ่ายไฟครั้งแรก

  • 1
    ตั้ง LM2596 ให้ได้ ~5.0V ด้วยมัลติมิเตอร์ ก่อนต่อเข้าบอร์ด
  • 2
    ต่อ flyback diode คร่อม solenoid ก่อนเสียบ 12V
  • 3
    Common GND — Adapter / Buck / ESP32 / CAM / Relay / Scanner ต้องร่วมกราวด์
  • 4
    Scanner TX → GPIO16 เท่านั้น อย่าสลับ TX/RX
  • 5
    Flash CAM ก่อน แล้วเปิดเบราว์เซอร์ทดสอบ /capture ให้ได้รูป
  • 6
    Flash Main ใส่ WiFi + Telegram token + chat id ใน credentials.h
  • 7
    CAM กับ Main ต้องอยู่ WiFi เดียวกัน และ gateway ตรงกับที่ตั้งใน credentials
